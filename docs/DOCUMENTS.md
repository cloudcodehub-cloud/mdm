# Documents / PDF output

## Engine

MDM generates printable documents on the server with **DomPDF** via `barryvdh/laravel-dompdf`. That package is PHP-only, works on ordinary shared hosting/cPanel, and does not require a browser process or a paid document API.

## Shared shell

Templates live under `resources/views/documents/`. Every document uses the same header/footer:

- MDM mark and product name
- Agency name from organization settings (never hard-coded)
- Document title, optional subtitle, and public record reference (client/employee numbers)
- Generated by the logged-in user name and role
- Generated timestamp in the organization timezone
- Confidentiality footer for client/workforce documents
- Page numbers on downloaded PDFs

Preview is an in-app HTML page (`…/documents/…`) with Back, Download PDF, and browser Print. Download routes return `application/pdf`.

## Authorization

PDF and preview URLs call the same Laravel policies as the source screens. Hiding a Print / PDF button is not sufficient — direct URLs return 403 when the user cannot view the record or report.

- Admin: organization-wide
- Supervisor: caseload/team only
- DSP: assigned visit/client documents already allowed by visit policies
- Hours / attendance PDF: Admin and Supervisor only (same as Reports)
